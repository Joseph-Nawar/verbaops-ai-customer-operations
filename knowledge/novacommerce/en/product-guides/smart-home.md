# Smart Home Guide

## Before installation

Confirm the device's network band, hub requirement, power source, and supported region. Use the manufacturer's application from an official store and update firmware before pairing other devices.

## Privacy and accounts

Use a separate strong password for the smart-home account and enable multi-factor authentication when offered. Review microphone, camera, location, and sharing permissions before enabling a feature.

## Troubleshooting

Check power, network reachability, account ownership, and firmware version in that order. A factory reset can remove local configuration, so follow the manufacturer's backup and reset instructions.
